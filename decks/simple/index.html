Setup


$ npm init
$ npm i --global typescript
$ npm i reveal.js
$ npm i --save-dev @types/reveal.js
$ npm install --save-exact --save-dev esbuild
$ mkdir public
$ cd public
$ ln -s ../node_modules/reveal.js
$ cd -
$ cat > .gitignore
node_modules/
dist/
^D
$ # create ßtsconfig.json
$ tsc

Adding a Plugin


$ npm install --save reveal.js-menu
$ mkdir typings
$ cat > typings/reveal.js-menu.d.ts
declare module 'reveal.js-menu' {
	const RevealMenu: Reveal.PluginFunction;
	export default RevealMenu;
}
^D
